# Tag vocabulary

Use only these tags in front matter. Put anything more specific (a protocol,
a product, a CVE, a tool name) in `keywords:` instead: the article schema
reads `keywords`, so search engines still see it, but it won't create a
one-post tag page.

Daily digests keep their own tags (`news`, `daily`, `ciso`, `governance`).
